The post-publication workflow repeated 110 scheduled, real-time break cycles with the exact published v1.2.1 executable. ## Remaining limitations

The exact published binaries passed the available hosted interactive lifecycle and resource tests. The following scenarios remain explicitly unverified or only partially observed:

- No native Windows 11 x64 machine was available; Windows 11 coverage used ARM64 x64 emulation.
- The ARM64 soak could not confirm foreground focus for 22 Escape-key attempts. Those attempts remain NOT TESTED.
- Narrator audible speech, physical speaker output, actual sleep/resume, and real lock/unlock were not verified.
- A separate visible Windows Shell toast was not observed; the in-app reminder window was exercised. These are distinct notification surfaces.
- Multiple-monitor behavior and changing physical display topology were not exercised.
- TaskDialog instruction-text extraction remains NOT TESTED. Four NSIS observations remain NOT TESTED: the finish-page run-checkbox result and extracted UI-process exit code for each of v1.2.1 and v1.1.0. The interactive uninstaller itself completed, and filesystem/shortcut/registry cleanup passed; the separately extracted process exit code was not captured.
- The hosted Windows acceptance suite also records a live timer tick during a network request as NOT TESTED; the update request itself, UI responsiveness, and countdown continuation were verified.

These limits do not indicate a confirmed release defect. The application and installer remain unsigned; SmartScreen reputation behavior and physical audibility are not claimed as verified.

## Final assessment

The published v1.2.1 binaries match the release manifest, launch, install, upgrade from v1.2.0, update-check, uninstall, and preserve settings/history as tested. The actual public executable completed 110 scheduled reminder cycles on Server 2025 x64 and Windows 11 ARM64 x64 emulation without sustained USER-object growth; both runs returned to Running with no open break windows. No new application defect was found, and no additional hotfix is indicated by these results.
