# Eye Break Reminder v1.4.0

v1.4.0 adds an in-app updater for native Windows 11 x64 installations and portable copies.

- Check for stable releases from **Settings → About**. Optional daily checks and background downloads are off by default. Installation always asks for confirmation.
- See download progress as bytes arrive. The updater verifies the publisher's signed manifest and the download's size and SHA-256 before launching setup or replacing the portable executable. The app relaunches and confirms startup.
- **Preserve my settings** is the default. **Clean install** resets settings and the active timer for an installed copy. It keeps history unless you separately choose and confirm deletion. Portable updates preserve settings and history.
- An interrupted update can roll back using the prior app and verified backups. Reinstalling to the original directory can repair missing or damaged app files once pending recovery has cleared. If setup reports a pending rollback and recovery cannot finish, keep the transaction folder and contact support. Missing or damaged backups can limit what can be recovered.
- Existing timer and break reminders, scheduling, pause and snooze controls, history and statistics, themes, high-contrast support, and custom work and break accent colours remain available.

**Upgrading from v1.3.0.** The existing checker can point you to the release. Download and run v1.4.0 Setup manually for this first upgrade. If you use a portable copy, close it and manually replace the executable in its existing folder with the one in the new portable ZIP.

**Windows trust.** The setup and standalone executable are Authenticode unsigned. Windows may display an unknown-publisher or SmartScreen warning. Use the official GitHub release and verify the downloaded checksum. The signed update manifest authenticates future updates for the app, and Windows publisher trust is a separate control.

**Known limits.** Automatic recovery after a real Windows reboot and sign-in has yet to be verified. Windows Settings uninstall, audible alarm and preview, lock and sleep transitions, multiple monitors, and Shell notification delivery have outstanding native desktop checks. Shell notifications are intentionally silent. The app alarm is a separate feature.
