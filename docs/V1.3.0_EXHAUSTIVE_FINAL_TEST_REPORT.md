The exact production executable SHA `e6ba8b8bead1b86cd0b07e990cc543b8ed8a8a691f73c70e310de35a3f0a6afd` completed 110 timed reminder cycles in 7,557.5 seconds, created 116 Break windows, opened the picker 100 times (50 OK/50 Cancel), and yielded 2,191 time-series samples. The full soak ran against this exact candidate; evidence was not reused from a different executable.

| Resource | Start median | End median | Range | Slope per reminder cycle |
|---|---:|---:|---:|---:|
| USER objects | 164 | 164 | 164–165 | +0.00126 |
| GDI objects | 58 | 59 | 57–62 | +0.01039 |
| Process handles | 238 | 238 | 237–240 | −0.00094 |
| Private bytes | 3.71 MB | 4.17 MB | 3.47–4.54 MB | +5.02 KB |

USER and handle medians remained flat. GDI changed by one median object with bounded range, not sustained growth proportional to cycles. Private bytes rose modestly; working set declined. The previous v1.2.1 leak regression was not weakened.

No confirmed product defect was found. No product rebuild was needed for these test-only corrections.
