## Release gate still blocked by publisher authenticity

No production signing key, signed update metadata key, or trusted Authenticode publisher certificate is provisioned. The updater validates the official repository/tag/asset, requires HTTPS, applies normal Windows certificate validation, validates GitHub's SHA-256 digest, limits payload size, and revalidates before installation. This protects against transport alteration and mismatch against GitHub metadata, but it does not independently prove publisher identity if the repository/account or GitHub release metadata is compromised. No test private key is included. The update publisher-authenticity requirement remains **BLOCKED** and release readiness cannot be claimed until an owner-provisioned signing trust root is available and verified.
