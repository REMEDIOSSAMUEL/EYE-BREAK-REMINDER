# Eye Break Reminder v1.4.2

This visual hotfix improves updater dialog backgrounds and radio controls, formats release notes as readable plain text, matches download-size precision, prevents clipped instructions, and gives the installation coordinator a clear completed state with theme-aware typography and spacing.

The authenticated update, payload verification, installation, settings/history handling, recovery, rollback and relaunch behavior are unchanged.

The currently installed version owns the dialogs and independent coordinator used while it installs v1.4.2. Those windows can retain the previous styling during this upgrade; the corrected v1.4.2 presentation applies when v1.4.2 is used for later update sessions.
