## Product / harness defects and corrections

1. **Interrupted-clean recovery launch reliability.** An earlier run restored the prior files but the app was not visible when checked. The coordinator was changed to keep RunOnce until startup confirmation, launch the restored version, and retry recovery phases without clearing state prematurely. The later hosted run verified the byte-identical restoration and launch after directly invoking the recovery command.
2. **RunOnce process-window test harness.** A prior harness used global `FindWindowW` and could select an unrelated or stale window. It now enumerates visible windows owned by the exact restored process and verifies image path, window class and title. Run 44179592402 passed the recovery-window assertion after this correction.
3. **NSIS interactive uninstall UI harness.** Run 44179592402 showed the Windows Server UIA provider reports NSIS's enabled native Button as a Pane with no InvokePattern. The current uncommitted harness verifies the exact executable lineage, PID, native class, parent wizard, enabled state and bounds, then sends a desktop mouse click if no UIA Invoke action exists. The current fix still requires hosted execution; no product uninstall defect is confirmed.
