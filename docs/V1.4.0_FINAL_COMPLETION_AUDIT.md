A separate workflow validates the raw records and passed independent audit and ARM64 without rerunning the soak.
4. **Focused test harness issues:** the low-space API fault injection itself passed; its separate ACL check initially used `%TEMP%` instead of the production `%LOCALAPPDATA%` parent, so the disposable root and object-ACE parsing were corrected. The failure-edge workflow initially failed before executing tests because `inputs.*` is empty on a push event; candidate-download IDs now fall back to the exact retained candidate defaults.
