## Defect and correction

The update-check worker was detached each time. The scoped correction stores the worker, joins it when its posted result is applied, and detaches only an in-flight worker during window destruction after dispatch is invalidated. Local and hosted targeted loops report 0.0 handle growth per cycle for check-only, dialog-visible, and dialog-dismissed phases.
